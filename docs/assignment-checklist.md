# Drill #14 제출 조건 대조

사용자가 첨부한 「새의 비행 애니메이션 구현 - AI 활용」 과제 이미지와
추가 요청을 기준으로 확인한다.

| 요구사항 | 구현 및 확인 근거 |
| --- | --- |
| 새 10마리 | `bird.py`의 `BIRD_COUNT = 10`, `play_mode.init()`의 생성 반복문. 자동 검증과 실제 렌더링에서 10개 객체 확인. |
| 좌우 반복 비행 | `Bird.update()`에서 각 새 크기를 반영한 좌우 경계와 왕복 경로를 계산. 두 경계의 반사, 초과 거리 보존, 3회 왕복 검증. |
| 지정 이미지 활용 | `Bird.image`에 `bird_animation.png`를 한 번 로드. 5열·3행 중 빈 칸을 제외한 14장 재생. |
| 정확한 비행 애니메이션 | 이동 거리와 날갯짓 진행량에 모두 `frame_time` 적용. 30·60·144 FPS와 불규칙 간격에서 같은 경과 시간의 결과 비교. |
| 개발 논리를 최종 커밋에 상세 설명 | 최종 커밋 본문에 단위 환산, 시간 누적, 스프라이트 선택, 좌우 반사, 크기 산식, 검증 결과를 기록. |
| 기존보다 작게 만들지 않고 크기 다양화 | 기본 폭 30px에 1.0~1.5배 적용. 폭 30~45px, 높이 약 27.56~41.34px. 생성 때 결정한 크기를 비행 중 유지. |
| 한국어 커밋 10회 이상 | 초기 커밋 이후의 과제 작업 이력으로 확인. 커밋 제목과 설명은 한국어로 작성. |

## 확인 명령

프로젝트 폴더에서 실행한다.

```powershell
python -m unittest discover -s tests -v
python scripts/check_bird_rendering.py
git log -1 --format=full
git log --oneline 587f3f1..HEAD
git rev-list --count 587f3f1..HEAD
```

마지막 명령은 초기 저장소 커밋 `587f3f1`을 제외한 과제 작업 커밋 수를 센다.
요청한 기준은 10개 이상이다. 저장소 전체 커밋 수는 초기 커밋 때문에 하나 더 많다.

## 범위와 가정

- 강의에서 가져온 것은 시간 기반 위치·액션 계산과 거리 축척이다.
- 30km/h, 날갯짓 0.5초, 기본 폭 0.9m는 이 구현에서 정한 값이다.
- 새 10마리는 각자의 높이에서 왕복한다. 무리의 대형이나 충돌 회피는 지정되지 않았다.
- 낮은 FPS에서는 중간 그림이 생략될 수 있다. 정확성이란 같은 경과 시간에 같은
  이동 거리와 날갯짓 위상을 갖는다는 뜻이며, 모든 환경의 시각적 부드러움을 보장하는 뜻은 아니다.
