# Drill14: 시간 기반 새 10마리 비행

`python main.py`로 실행한다. 기존 소년의 방향키 이동과 Space 공 발사,
Esc 종료를 유지하고, 하늘에 새 10마리를 추가했다.
실행 환경에는 `pico2d`, `PySDL2`, `transitions`가 필요하다.

## LEC16 적용 논리

참고 자료는 `LEC16_시간.pdf`이다.

- 16~20쪽: 이동 거리는 `속도(pixel/s) × frame_time(s)`로 계산한다.
- 19, 23쪽: `10 pixel = 30 cm`, 즉 `PIXEL_PER_METER = 10 / 0.3`을 사용한다.
- 28~29쪽: 애니메이션 프레임을 실수로 누적하고 그릴 때만 `int()`로 바꾼다.

프레임 시간은 `game_framework`에서 `time.perf_counter()`의 차이로
갱신 직전에 측정한다. 시스템 시계 조정의 영향을 받지 않으며,
모든 새가 같은 경과 시간을 사용한다. 매 프레임의 콘솔 출력은 제거했다.
강의의 `time.time()` 대신 경과 시간 측정용 시계를 사용한 구현상 개선이다.

## 비행과 날갯짓

새의 종과 속도, 크기, 날갯짓 주기는 강의에 지정되어 있지 않으므로
다음 값은 이 과제를 위한 가정이며 실제 새를 측정한 값은 아니다.

- 비행 속도: **30 km/h = 8.333… m/s = 277.777… pixel/s**.
  따라서 반사 전 1초 동안 약 277.78px를 이동한다.
- 날갯짓: **0.5초에 한 주기**, 한 주기는 **14장**이므로 초당 28장을 진행한다.
  `frame = (frame + 28 * frame_time) % 14`로 누적한다.
  화면 FPS가 낮아지면 중간 그림은 건너뛰더라도 이동 속도와 주기는 유지된다.
- 이미지: `bird_animation.png`는 **918×506px, 5열×3행**이다.
  위에서 아래, 각 행은 왼쪽에서 오른쪽 순서로 재생하며 마지막 빈 칸은 제외한다.
  각 칸의 경계를 이미지 크기의 비율로 계산한 뒤 정수화하여 나머지 픽셀을 처리한다.
  위쪽 기준 행 좌표를 pico2d의 아래쪽 기준 자르기 좌표로 변환한다.
- 이동 방향: 원본은 오른쪽을 보므로 왼쪽으로 갈 때 수평 반전한다.
  화면 양끝에서는 새 폭의 절반을 여백으로 두고 반사한다.
  왕복 경로의 길이로 나머지를 계산해, 지연된 프레임이 여러 경계를 넘어도
  남은 이동 거리를 보존한다.
- 10개 객체는 이미지를 한 번만 로드해 공유한다. 시작 가로 위치는 나누어 배치하고
  높이·방향·날갯짓 시작 프레임은 각각 무작위로 정한다.
  개별 수평 왕복 비행이며 새 사이의 충돌이나 군집 조향은 구현 범위에 포함하지 않았다.

## 새 크기를 정한 근거

한 프레임의 기본 가로 길이를 가상 세계에서 **0.9m**로 가정했다.
강의 축척을 그대로 적용하면 `0.9 × (10 / 0.3) = 30px`이다.
각 새를 생성할 때 **1.0~1.5배**의 배율을 무작위로 한 번 정해,
기존 크기보다 작아지지 않으면서 크기에 차이를 주었다.
출력 폭은 **30~45px**이며 가상 세계의 길이로는 **0.9~1.35m**이다.
높이는 원본 셀의 가로세로 비율을 유지하여
`출력 폭 × (506 / 3) / (918 / 5)`로 계산하므로 **약 27.56~41.34px**가 된다.
이는 투명 여백을 포함한 출력 사각형 크기이며 새 몸통 자체의 실측 크기는 아니다.
렌더러가 최종 픽셀 좌표를 정수화하므로 실제 출력에는 픽셀 단위 반올림 오차가 있다.
날갯짓 중에도 각 새의 출력 크기를 고정하여 프레임마다 새가 커지거나 작아지지 않는다.
시작 위치와 화면 끝의 반사 경계에도 각 새의 실제 출력 크기를 사용한다.

## 검증

`python -m unittest discover -s tests -v`

동일한 경과 시간을 30·60·144 FPS와 불규칙한 간격으로 나누었을 때의 위치,
날갯짓 위상, 긴 프레임의 경계 반사, 14장 자르기와 좌우 반전,
이미지 공유, 새 10마리 등록을 확인한다.

추가로 SDL 소프트웨어 렌더러에서 실제 리소스를 로드하여 600번 갱신하고,
14개 애니메이션 셀을 모두 렌더링했다. 시작·중간·종료 화면을 캡처해
새 10마리 표시, 투명 배경, 좌우 방향, 화면 내 배치를 확인했다.
